# Fred Campos Portfolio

A personal portfolio and resume website for Fred Campos, a Senior Software Engineer specializing in data infrastructure. The site highlights selected software projects, technical skills, professional experience, education, certifications, and contact information.

## Pages

- `index.html` — Portfolio overview with GitHub projects, technical skills, and contact links.
- `resume.html` — Detailed professional resume.

## Technology

The site is built with static HTML and CSS. It uses Google Fonts (Inter and Fira Code) and requires no build step or JavaScript framework.

## Run locally

Open `index.html` in a browser, or serve the project directory with any static file server.
